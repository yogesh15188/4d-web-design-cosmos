# 4D Web Design Cosmos — The Hyperdimensional Encyclopedia & AI Prompt Engine

An interactive 4D web experience, architectural design taxonomy, and master generative AI prompt compiler cataloging **40 distinct web design movements** across digital history.

---

## 🌟 Overview

The **4D Web Design Cosmos** transcends traditional 2D web showcases by incorporating:
- **Spatial 3D & 4D (Three.js WebGL)**: Real-time projection of a 4-dimensional hypercube (Tesseract), 4D Glome (Hypersphere), and Clifford Torus with camera parallax and quantum starfield particles.
- **Temporal 4th Dimension (Time Scrubber)**: An interactive timeline spanning from **1993 Web 1.0 to 2035+ Spatial Holography**. Scrubbing alters ambient acoustic frequencies, color temperatures, and epoch narratives in real-time.
- **Live 4D Aesthetic Chameleon**: An interactive hardware specimen (nested double-bezel cards, metrics, toggle switches, and CTAs) that physically morphs its CSS, borders, typography, and lighting models into any selected design style on the fly.
- **Universal Prompt Compiler**: Generate production-ready prompts for Midjourney v6, Flux.1, Claude 3.5 Sonnet, v0, and Antigravity.
- **Web Audio API Synthesizer**: Haptic synthetic sound effects for dimensional warps, card hovers, and button interactions (with full mute/unmute control).

## 🚀 Getting Started

The application is completely self-contained in `index.html`. No build steps or package managers are required.

Simply open `index.html` in any modern web browser:
```bash
# Double click index.html or start a local server:
npx serve .
# Or open directly in Edge / Chrome:
start index.html
```

## ⚡ Features & Usage

1. **Test Any Style Live**: In the **4D Aesthetic Chameleon** section, click on any style pill to instantly morph the specimen into that aesthetic.
2. **Compile Tailored AI Prompts**: Use the **Universal Prompt Synthesizer** dropdowns to combine any style with project types and color moods.
3. **Download All Prompts**: Click the **Download .MD** button in the header or taxonomy section to export the complete prompt matrix markdown file.
4. **Scrub Temporal Epochs**: Drag the timeline slider in the hero section to traverse digital history from 1993 to 2035+.
